# Visual reference and attribution

Thought Window's terminal panel treatment, deep-sea palette and animation vocabulary reference:

**world-execute-me-dsh-pv**, by MisakaZentai

https://github.com/MisakaZentai/world-execute-me-dsh-pv

Reference files: `film/tui_pv_world_execute_20260926/tuikit.py`, especially its `deepsea` palette and terminal `box` drawing primitive; and its TUI event/list presentation. The browser implementation is adapted to React/CSS/SVG and live public DSH conversation events. It does not render the reference project's video timeline.

Version 0.4 also studies `full/transitions.py` (reflow, camera pan/zoom), `continuity_full_v2/cuts.py` and `kit.py` (outgoing/incoming layers, carriers and eased paths), `s_sft.py` (grid/camera continuity), `scenes_eval.py` (a persistent focus cell), and `scenes_exec.py` (glyph banners and process registers). These ideas are reimplemented with bounded SVG diagrams and Web Animations for real-time conversation events. Words come from visible source excerpts; point fields are decorative, not model parameters, token embeddings, attention weights or training telemetry. The new code does not replay the song's storyboard or copy its artwork.

Version 0.5 was developed after cloning upstream commit `a598092a1b1db91fa43961a81269353d13419f6f` and studying `docs/HOW_IT_WORKS.md`, `full/engine.py`, `full/sec_verse1.py`, and the continuity kit/cuts. A local study rendered the original rope panel, terminal box and CRT post-processing primitives without the soundtrack. The plugin translates fixed chrome, persistent source objects and carrier continuity into a reader-paced queue with exact public-source offsets, semantic layouts and a source-order route. It does not reproduce the music timeline or claim access to model internals.

The whale actor is drawn from the DeepSeek mark that DeepSeek Harness itself serves as `/favicon.svg`; the plugin reads it from the host at runtime and does not include or redistribute the mark. Without it, a hand-drawn whale in the same pose is used.

The plugin does not distribute that project's music, lyrics, character artwork, screenshots, Windows fonts, or rendered video. Its diagram marks and animation are drawn by code and its font stack uses the fonts already installed on the device.
